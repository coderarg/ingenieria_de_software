## Dominios de Aplicación de Software
</br>

### Software de Sistemas
Programas que dan servicios a otros programas. Tienen contacto directo con el hardware con el fin de gestionar los recursos físicos del ordenador como ejecución de procesos o gestión de memoria RAM.
</br>

### Software de Aplicaciones
Programas aislados que cumplen una necesidad específica de negocio. Sirven para procesar datos comerciales o técnicos.
</br>

### Software de ingeniería y ciencia
Se utilizan en aplicaciones científicas como la astronomía, física, termodinamia, gestion de datos de consumos energéticos.
</br>

### Software de Webapps
Sitios web levandaos en servidores que permiten el acceso de forma pública. Estas son cada vez más modernas y potentes, permitiendo ejecutar programas empresariales, ERP, ticketeras, plataformas de entretenimiento, etc.
</br>

### Software Incrustado
Es software que se utiliza para una función muy puntual de algún objeto. Por ejemplo, placas de arduino, micro PLC, la ECU de los vehículos automotores o el software que corre en la plaqueta de una cafetera moderna con temporizador multifunción.
</br>
